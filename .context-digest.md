## 3. DROP-IN CODE BLUEPRINTS

### A. MVI BaseViewModel Blueprint
```kotlin
class FeatureViewModel(
    private val savedStateHandle: SavedStateHandle,
    private val featureUseCase: FeatureUseCase
) : BaseViewModel<FeatureState, FeatureIntent, FeatureEffect>(
    initialState = FeatureState(
        id = savedStateHandle[KEY_ID] ?: "",
        query = savedStateHandle[KEY_QUERY] ?: ""
    )
) {
    companion object {
        private const val KEY_ID = "feature_id"
        private const val KEY_QUERY = "feature_query"
    }

    override fun onIntent(intent: FeatureIntent) {
        when (intent) {
            is FeatureIntent.UpdateQuery -> {
                savedStateHandle[KEY_QUERY] = intent.query
                setState { copy(query = intent.query) }
            }
            is FeatureIntent.Submit -> safeLaunch {
                setState { copy(isLoading = true) }
                featureUseCase(state.value.query).fold(
                    onSuccess = { result -> setState { copy(isLoading = false, items = result) } },
                    onFailure = { err -> 
                        setState { copy(isLoading = false) }
                        setEffect { FeatureEffect.ShowToast(err.message ?: "Error") }
                    }
                )
            }
        }
    }
}
```

fun FeatureScreen(
    state: FeatureState,
    onIntent: (FeatureIntent) -> Unit,

        modifier = modifier

            text = stringResource(R.string.feature_title),
            style = AppTypography.headlineMedium,

            onClick = { onIntent(FeatureIntent.Submit) },
            modifier = Modifier
                .fillMaxWidth()
                .minimumInteractiveComponentSize() // Min 48x48dp touch target
                .heightIn(min = 48.dp)
        ) {
            AppText(text = stringResource(R.string.btn_submit), style = AppTypography.labelLarge)
        }
    }
}

class FeatureRepositoryImpl(
    private val localDao: FeatureDao,
    private val remoteApi: FeatureApiService,
    private val database: AppDatabase
) : FeatureRepository {

    override fun getItems(): Flow<Resource<List<FeatureItem>>> = networkBoundResource(
        query = { localDao.getAllItems().map { it.map(FeatureEntity::toDomain) } },
        fetch = { remoteApi.fetchItems() },
        saveFetchResult = { remoteList ->
            database.withTransaction {
                localDao.deleteAll()
                localDao.insertAll(remoteList.map(FeatureDto::toEntity))
            }
        },
        shouldFetch = { localList -> localList.isEmpty() }
    )
}

## 4. ANTI-PATTERNS & FORBIDDEN PRACTICES (DOs & DON'Ts)

| CATEGORY | ❌ ABSOLUTELY FORBIDDEN (DON'T) | ✅ MANDATORY PATTERN (DO) |
| :--- | :--- | :--- |
| **State** | `viewModelScope.launch` / Extend `ViewModel()` directly | Use `safeLaunch` / Extend `BaseViewModel<State, Intent, Effect>` |
| **Colors** | `Color(0xFF...)`, `Color.White`, `Color.Black` inline | `AppTheme.colors.surface`, `AppTheme.colors.primary` |
| **Dimensions** | Hardcoded `16.dp`, `24.dp` | `AppSpacing.medium`, `AppSpacing.large`, `AppShapes.*` |
| **Strings** | `Text("Hello")` hardcoded string | `AppText(text = stringResource(R.string.hello))` |

| **Security** | Plaintext SharedPreferences for tokens | `EncryptedSharedPreferences` + Android Keystore |

| **Over-Engineering**| 1-line delegate UseCases / Hand-rolled helpers / Bloat libs | Ponytail Minimalist: Native Compose M3 / Kotlin Stdlib / Single-expr `=` (Rule 32) |

## 6. CTO/PO PROACTIVE ADVISORY & HEURISTICS MATRIX (ANTI-YES-MAN)

### A. CTO Performance Heuristics (Zero-Jank & Low Heap)
1. **Recomposition Stability**: Never pass unstable params into leaf composables. Memoize all lambdas with `remember` or method references (`::onClick`).
2. **Heap Allocations**: Zero object allocations inside `@Composable` body (No `Regex`, `SimpleDateFormat`, or new lists during scroll). Use `@JvmInline value class` and `mutableIntStateOf`.
3. **Main-Thread Budget**: Max 5ms on Main. Offload DB, JSON parsing, and heavy math to `Dispatchers.Default` / `Dispatchers.IO`.

### B. PO UI/UX Excellence Heuristics (World-Class Product)
1. **5-State Completeness**: Every screen MUST implement: `Loading Skeleton`, `Content/Success`, `Empty State` (with CTA), `Error State` (with Retry), and `Offline State` (with Banner).
2. **Defensive Layout**: No collisions (`Modifier.align()` in Box), no text overflow in Row (`weight(1f)` + `Ellipsis`), wrap chips in `FlowRow`.
3. **Touch Targets & Scaling**: Minimum 48x48dp interactive bounds (`minimumInteractiveComponentSize()`). Support 200% non-linear font scaling.
4. **Insets & IME**: Always use `WindowInsets.safeDrawing` and `.imePadding()`. Virtual keyboard must NEVER obscure active input fields.

### C. Standard CTO/PO Advisory Response Format
- 🎯 **CTO/PO Assessment**: Validate business intent and core value.
- ⚠️ **Critical Risks & Bottlenecks**: Expose performance traps, recomposition issues, or UX dead-ends.
- 💡 **Recommended Architectural Solution**: Present superior alternative with Before vs After comparison and clean drop-in code.
